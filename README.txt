Craftora website
================
Open index.html in any browser.

index.html   page markup
images/      all photos (extracted from the page)
css/         all stylesheets (extracted from the page)
js/          all scripts (extracted from the page)

Still loaded online (not bundled): Tailwind CSS (cdn.tailwindcss.com) and the
Cormorant Garamond / Plus Jakarta Sans fonts (Google Fonts). Keep an internet
connection, or download those and point the links at local copies.
